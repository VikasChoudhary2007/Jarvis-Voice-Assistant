# 🤖 JARVIS — Python Voice Assistant

### 🎙️ Your Personal AI-Powered Voice Assistant

*Built with Python, AI, APIs & Voice Recognition*

---

## ✨ What Can Jarvis Do?

🎙️ **Voice Recognition**  
Understands your voice commands

🤖 **AI Assistant**  
Answers questions using OpenAI

🌐 **Web Control**  
Opens Google, YouTube, Facebook & LinkedIn

🎵 **Music Player**  
Plays songs using voice commands

📰 **News Updates**  
Fetches the latest news headlines

🔊 **Text-to-Speech**  
Responds using voice

🛑 **Voice Shutdown**  
Say **"Stop"** to close Jarvis

---
